# 发布检查清单

上架前逐项确认。**带 ⚠️ 的项目若未处理，会造成数据泄露或资金损失。**

## 一、必须停用 ⚠️

### 1. 移除调试工具入口

`miniprogram/pages/profile/profile.js` 与 `profile.wxml` 中的
**调试工具**区块包含「初始化测试数据」和「重置数据」按钮。
演示数据会覆盖正式数据，任何用户都能触发。

处理方式（二选一）：

**方案 A —— 直接删除**（推荐）

删除 `profile.wxml` 中调试工具区块，对应删除 `profile.js` 中的处理函数。

**方案 B —— 用编译条件隔离**

在 `app.js` 中区分环境：

```javascript
App({
  globalData: {
    env: 'development'   // 上线前改为 'production'
  }
})
```

`profile.wxml`：

```xml
<view wx:if="{{appEnv === 'development'}}" class="debug-section">
  <!-- 调试工具 -->
</view>
```

### 2. 删除 `initTestData` 云函数 ⚠️

即使前端入口已移除，云函数仍可被直接调用。**从云端删除该函数**，
并从仓库中移除 `cloudfunctions/initTestData/`。

### 3. 校验支付回调 ⚠️

当前 `createOrder` / `createConsultation` **未接入微信支付官方校验**。
在接入真实支付校验前：

- 不要开放任何付费入口
- 或将 `vip` / `consulting` 页面的购买按钮置灰

原因：仅凭客户端参数创建订单可以被伪造，属于资金风险。

## 二、配置核查

### 4. 确认使用的是自己的 AppID

`project.config.json` 中的 `appid` 必须是你自己的。
若使用了本仓库的默认值，需要替换。

### 5. 确认云环境 ID

`miniprogram/app.js` 中的 `env` 必须指向你的环境，
且该环境已开通云存储。

### 6. 数据库权限复查 ⚠️

逐个集合确认（云开发控制台 → 集合 → 权限设置）：

| 集合 | 期望权限 |
|:--|:--|
| `projects` | 所有用户可读，仅创建者可写 |
| `users` | 所有用户可读，仅创建者可写 |
| `comments` | 所有用户可读，仅创建者可写 |
| `likes` | 所有用户可读，仅创建者可写 |
| `favorites` | 所有用户可读，仅创建者可写 |
| `orders` | 仅创建者可读写 |
| `consultations` | 仅创建者可读写 |
| `advisors` | 所有用户可读，任何人不可写 |

**实测方法**：用两个不同微信账号分别登录，确认 A 无法读取和修改 B 的数据。

### 7. 清理演示数据

如需保留演示数据用于展示，请确认这些记录不会与真实内容混淆——
建议在 `projects` 中给演示数据打上 `isDemo: true` 标记，首页过滤掉。
