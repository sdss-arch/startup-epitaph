# 设计规范

复古怀旧风。碑、纸、墨、拓片——这是整个产品的视觉基调。

## 硬性约束

> **严禁使用蓝紫色。**

这不是偏好，是产品级约束。任何提交中引入蓝紫色，PR 会被要求修改。

## 颜色

| 用途 | 色值 | 应用位置 |
|:--|:--|:--|
| 主色 · 深棕 | `#2c2416` | 导航栏背景、标题文字、选中态 Tab 图标 |
| 背景 · 米色 | `#f5f0e6` | 页面背景、TabBar 背景 |
| 次要 · 棕 | `#8b7355` | 说明文字、未选中态 Tab 图标、分割线 |

定义位置：`miniprogram/app.json`（导航栏与 TabBar）、
`miniprogram/app.wxss`（全局样式）。

新增颜色前先确认不属于蓝紫色相区间（色相角 200°–320°）。

## 字体

以衬线体为主，呼应碑文质感：

```
Georgia, "Songti SC", "SimSun", serif
```

标题可加字重，正文不加。

## 布局

- 卡片式布局，圆角 + 细分割线
- 卡片模拟碑石的方正感，避免圆润可爱风
- 间距统一使用 8 的倍数

## 组件基调

| 元素 | 要求 |
|:--|:--|
| 按钮 | 直角或微圆角，不要胶囊形 |
| 标签 | 描边风格，不用实心色块 |
| 头像 | 低饱和、复古调色，避免高饱和撞色 |
| 分割线 | 浅棕细线，不用灰色 |

## 交互反馈

| 状态 | 处理 |
|:--|:--|
| 按下 | 轻微透明度变化，不做缩放弹跳 |
| 加载中 | 使用文字提示，不用旋转菊花（破坏基调） |
| 空状态 | 一句克制的文案，不用插画 |
| 错误 | 说明原因 + 可执行的下一步 |

## 文案基调

- 克制、具体，不煽情
- 描述失败时对事不对人
- 避免"创业鸡汤"和"必须""一定"这类绝对化表述
- 数字优先于形容词：「烧了 340 万，撑了 14 个月」优于「一次沉重的失败」

## 内容规范

- 金额一律标明单位（元／万元）
- 时间用「持续 X 个月」而非模糊表述
- 行业分类沿用既定分类，不自造
- 尊重匿名：发布者选择隐去公司名时，不得通过其他字段反推
