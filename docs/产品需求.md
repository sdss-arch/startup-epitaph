# 产品需求

## 一句话定位

一个汇集失败创业项目的微信小程序——为每一次失败立碑，让教训可以被检索、被复用。

## 要解决的问题

创业复盘信息目前散落在朋友圈、知乎回答、关停的公众号里。三个后果：

1. **搜不到** —— 内容孤立，没有结构，无法按行业、时间、金额检索
2. **传不下** —— 平台一关停，内容随之消失
3. **没人看** —— 长文劝退，缺少入口和浏览路径

结果是：每次创业失败，付出的代价无法沉淀为下一次的判断依据。

## 核心洞察

失败案例的价值不在于「 sympathy」，而在于**因果链完整**：

```
项目是谁 → 做了什么 → 花了多少钱 → 死于什么原因 → 留下什么教训 → 今天还有没有机会
```

其中最后两项是差异化重点。多数失败案例集只记录到「怎么死的」，
本项目要求发布者必须回答「留下什么」和「今天还有没有机会」。

## 功能规格

### 浏览侧

| 功能 | 要求 |
|:--|:--|
| 项目列表 | 卡片流，支持 全部／最新／热门 三种排序 |
| 交互 | 下拉刷新 + 上拉加载分页 |
| 详情 | 完整字段展示、点赞致敬、收藏、评论、浏览量统计、分享转发 |
| 搜索 | 关键词检索 + 行业分类筛选 |
| 数据看板 | 项目总数、总投入金额、总浏览量、总致敬数、行业分布 |

### 贡献侧

| 功能 | 要求 |
|:--|:--|
| 发布 | 完整表单，含字段校验、照片上传、标签管理 |
| 编辑 | 修改已发布项目内容与照片 |
| 删除 | 仅限本人 |
| 演示数据 | `initTestData` 一键灌入 6 条样例 |

### 账号侧

| 功能 | 要求 |
|:--|:--|
| 登录 | **静默登录**，无授权弹窗，`wx.cloud` 隐式换取 openid |
| 资料 | 昵称、头像、简介 |
| 我的 | 我的项目、我的收藏、消息通知、数据看板 |

### 商业化侧（可选）

| 功能 | 要求 |
|:--|:--|
| VIP | 会员订阅页 + 权益说明 |
| 咨询 | 付费咨询下单 |
| 订单 | `createOrder` / `createConsultation` |

详见 [商业化](商业化.md)。

## 硬性约束

| 约束 | 说明 |
|:--|:--|
| **严禁蓝紫色** | 产品级视觉约束，任何界面不得出现 |
| 复古怀旧风 | 棕色 / 米色 / 灰色系，衬线字体 |
| 逻辑闭环 | 所有页面与功能完整开发，不留占位页、不留死链 |
| 云开发 | 必须使用云函数 + 云数据库，不引入自建后端 |
| 静默登录 | 不得弹出授权弹窗 |

## 信息架构

```
底部 TabBar
├── 墓志铭（首页）    项目流
├── 搜索              检索 + 筛选
├── 立碑（发布）      贡献入口
└── 我的              账号中心
     ├── 我的项目
     ├── 我的收藏
     ├── 编辑资料
     ├── 数据看板
     ├── 消息通知
     ├── VIP
     └── 创业咨询
```

二级页面：`项目详情`、`编辑项目`。

## 设计令牌

| 用途 | 色值 |
|:--|:--|
| 主色（深棕） | `#2c2416` |
| 背景（米色） | `#f5f0e6` |
| 次要文字（棕） | `#8b7355` |

TabBar 图标 81×81，每个 tab 两枚（未选中 / 选中），共 8 枚。

## 技术约束

| 层 | 选型 |
|:--|:--|
| 前端 | 微信小程序原生，无第三方 UI 库 |
| 后端 | 腾讯云开发（云函数 + 云数据库 + 云存储） |
| 运行时 | 基础库 ≥ 2.2.3，Node.js，`wx-server-sdk ~2.6.3` |

## 非目标

以下明确不在当前版本范围内：

- 用户间的私信 / IM
- 视频与音频内容
- 多语言 / 国际化
- 原生 App 或 H5 版本
