## 二、创建云开发环境

1. 打开微信开发者工具，导入本项目
2. 工具栏点击 **云开发**
3. 点击 **开通**，填写环境名称（例如 `创业墓志铭`）
4. 记下生成的**环境 ID**，形如 `cloud1-xxxxxxxx`

> 环境 ID 在下一步要用到。创建后不会频繁变动，但重建环境会导致小程序无法访问旧数据。

## 三、修改项目配置

本仓库为了让 clone 即可编译，保留了原始配置。**你必须改成自己的**：

### 3.1 小程序 AppID

`project.config.json`：

```json
{
  "appid": "wx0000000000000000"
}
```

替换为你的小程序 AppID。修改后建议不要将该文件回退，避免误提交他人 AppID。

### 3.2 云环境 ID

`miniprogram/app.js`：

```javascript
wx.cloud.init({
  env: 'cloud1-xxxxxxxx',   // ← 换成你的环境 ID
  traceUser: true
});
```

## 四、创建数据库集合

云开发控制台 → **数据库** → **添加集合**，依次创建 5 个：

| 集合名 | 用途 | 字段定义 |
|:--|:--|:--|
| `projects` | 项目档案 | 详见 [数据模型](数据模型.md) |
| `users` | 用户资料 | 同上 |
| `comments` | 评论 | 同上 |
| `likes` | 点赞记录 | 同上 |
| `favorites` | 收藏记录 | 同上 |

创建步骤：

1. 输入集合名称
2. 确定
3. 点击刚创建的集合
4. 进入 **权限设置**
5. 选择「所有用户可读，仅创建者可写」
6. 保存
7. 重复以上步骤创建其余 4 个

## 五、配置数据库权限

权限设置是本项目**最容易出错、后果最严重**的一步。
错误的权限规则可能导致用户数据被他人读取或篡改。

### 5.1 5 个基础集合

统一设为「所有用户可读，仅创建者可写」，对应规则：

```json
{
  "read": true,
  "write": "doc._openid == auth.openid"
}
```

`_openid` 由云开发自动注入，客户端无法伪造，因此该规则是可信的。

### 5.2 商业化集合（如启用付费功能）

`orders`、`consultations` 只能本人读写：

```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

`advisors` 全员可读、**任何人不可写**（仅控制台可维护）：

```json
{
  "read": true,
  "write": false
}
```

### 5.3 验证权限配置

部署完成后，在云开发控制台 → 数据管理中抽查任意一条记录，
确认客户端 `db.collection('projects').get()` 只能取到公开数据，
而 `db.collection('orders').get()` 取不到他人订单。

## 六、部署云函数

在开发者工具文件树中，**对 `cloudfunctions` 下每个函数目录**：

1. 右键点击函数文件夹
2. 选择 **上传并部署：云端安装依赖**

需部署的 8 个函数：

| 函数 | 作用 | 必需 |
|:--|:--|:--|
| `login` | 静默登录换取 openid | ✅ |
| `publishProject` | 发布项目 | ✅ |
| `updateProject` | 更新项目 | ✅ |
| `deleteProject` | 删除项目 | ✅ |
| `initTestData` | 灌入演示数据 | ✅（上线前停用） |
| `createOrder` | 创建订单 | 商业化 |
| `createConsultation` | 创建咨询订单 | 商业化 |
| `sendNotification` | 消息通知 | 商业化 |

等待底部状态栏显示部署完成。全部 8 个函数应出现在云开发控制台的云函数列表中。

## 十、常见问题

### `database collection not exists: projects`

数据库集合未创建。回到第四步，确认 5 个集合都已创建且名称完全一致。

### 云函数调用失败

1. 确认云函数已「上传并部署：云端安装依赖」
2. 确认 `app.js` 中的 `env` 与实际环境 ID 一致
3. 在开发者工具 → 云开发 → 云函数 → 日志中查看具体报错

### 静默登录无响应

基础库版本低于 2.2.3 会导致 `wx.cloud` 不可用。检查 `project.config.json` 中的
`libVersion`，并确认控制台无报错。

### 图片上传失败

云存储未开通。云开发控制台 → **存储** → 开通。

### 演示数据看不到

1. 确认 5 个集合都已创建
2. 确认 `initTestData` 已部署
3. 确认集合权限不是「仅创建者可读写」——演示数据的 `_openid` 属于云函数上下文，
   用「所有用户可读」才能在列表里看到

### 如何重置演示数据

我的 → 底部调试工具 → **重置并重新初始化**。

### 提交了别人的 AppID 怎么办

`git rm --cached project.config.json` 将其移出索引，
加入 `.gitignore`，然后在本地重建该文件。

## 十一、正式发布

1. **移除调试工具**（见[发布检查清单](发布检查清单.md)）
2. 微信公众平台配置：名称、简介、图标、类目
3. 接入微信支付（如启用商业化），配置商户号、API 密钥、支付证书、回调地址
4. 提交审核
5. 通过后发布

> 小程序支付需要 ICP 备案，咨询服务涉及相关资质，详见
> [商业化 · 合规提示](商业化.md#注意事项)。
