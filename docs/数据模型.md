# 数据模型

## 数据库集合

### 1. projects (项目集合)
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | String | 项目ID（自动生成） |
| _openid | String | 创建者openid |
| title | String | 项目名称 |
| description | String | 项目简介 |
| industry | String | 行业分类 |
| duration | Number | 持续时间（月） |
| cost | Number | 总花费（元） |
| teamSize | Number | 团队规模 |
| failureReason | String | 失败原因分析 |
| lessonsLearned | String | 经验教训 |
| marketPotential | String | 市场潜力评估 |
| tags | Array | 标签数组 |
| photos | Array | 项目照片URL数组 |
| status | String | 状态：'failed'(已失败), 'archived'(归档) |
| views | Number | 浏览次数 |
| likes | Number | 点赞数 |
| createdAt | Date | 创建时间 |
| updatedAt | Date | 更新时间 |

### 2. users (用户集合)
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | String | 用户ID（自动生成） |
| _openid | String | 用户openid |
| nickname | String | 昵称 |
| avatarUrl | String | 头像 |
| bio | String | 个人简介 |
| projectsCount | Number | 发布项目数 |
| createdAt | Date | 创建时间 |
| updatedAt | Date | 更新时间 |

### 3. comments (评论集合)
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | String | 评论ID（自动生成） |
| _openid | String | 评论者openid |
| projectId | String | 项目ID |
| content | String | 评论内容 |
| nickname | String | 评论者昵称 |
| createdAt | Date | 创建时间 |

### 4. likes (点赞集合)
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | String | 点赞ID（自动生成） |
| _openid | String | 点赞者openid |
| projectId | String | 项目ID |
| createdAt | Date | 创建时间 |

### 5. favorites (收藏集合)
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | String | 收藏ID（自动生成） |
| _openid | String | 收藏者openid |
| projectId | String | 项目ID |
| createdAt | Date | 创建时间 |
