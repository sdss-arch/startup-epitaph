## 🔧 技术实现

### 数据模型新增

#### 1. users（用户表，新增字段）
```javascript
{
  isVip: false,         // 是否VIP会员
  vipExpireAt: Date,   // VIP到期时间
  vipLevel: 1,          // VIP等级
}
```

#### 2. orders（订单表）
```javascript
{
  orderNo: String,      // 订单号
  type: 'vip|consult',  // 订单类型
  amount: Number,       // 金额（分）
  status: String,       // 状态：pending|paid|cancelled
  userId: String,
  createdAt: Date
}
```

#### 3. advisors（导师表）
```javascript
{
  name: String,
  avatar: String,
  title: String,
  bio: String,
  industry: String,
  tags: Array,
  price: Number,        // 咨询价格
  rating: Number,
  consultCount: Number,
  isVip: Boolean,
  status: 'active',
  sort: Number
}
```

#### 4. consultations（咨询记录表）
```javascript
{
  advisorId: String,
  advisorName: String,
  userId: String,
  price: Number,
  status: 'pending|confirmed|completed|cancelled',
  rating: Number,
  createdAt: Date
}
```

## 🚀 部署前准备

### 1. 微信支付配置
需要在微信公众平台配置：
- 商户号
- API密钥
- 支付证书
- 回调地址

### 2. 云开发新增集合
在云开发控制台创建：
```javascript
- orders         // 订单表
- advisors       // 导师表
- consultations  // 咨询记录表
```

### 3. 数据权限配置
```javascript
orders: {
  read: "doc._openid == auth.openid",
  write: "doc._openid == auth.openid"
}

advisors: {
  read: true,
  write: false  // 仅管理员可写
}

consultations: {
  read: "doc._openid == auth.openid",
  write: "doc._openid == auth.openid"
}
```

## ⚠️ 注意事项

1. **合规性**
   - 小程序支付需要ICP备案
   - 咨询服务需要考虑相关资质
   - 广告内容需要审核

2. **用户体验**
   - 控制广告频率，避免影响体验

   - 咨询服务质量把控

3. **技术实现**
   - 真实支付需要接入微信支付API
   - 需要完善订单系统和退款流程
   - 建议添加消息通知功能
